# lil.j

Website sinh nhật **Vũ trụ của em** / **Your universe**. Giao diện tiếng Việt và tiếng Anh. Tên giả trong bản mẫu là J. Đường đi một chiều: cổng, bầu trời, bản đồ sao đêm sinh, ảnh, câu đố, đồng hồ, bánh, ước, rồi lá thư cuối.

- [`site/`](./site/) — trang React + Vite. Sửa nội dung ở [`site/content.json`](./site/content.json). Hướng dẫn tiếng Việt: [`site/README.md`](./site/README.md).
- [`tools/fb-photo-downloader/`](./tools/fb-photo-downloader/) — tải ảnh Facebook đang xem được (userscript / console), rồi (tuỳ chọn) nén WebP cho site. Xem README tiếng Việt trong thư mục đó.

```bash
cd site
npm install
npm run dev
```
